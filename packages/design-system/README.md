# Design System

This package holds shared design tokens and modern visual defaults for GoHealTrail.

## Current tokens
- **Palette**: background/dark glass, cyan and emerald accents
- **Spacing**: 6/10/14/20/28 scale
- **Typography**: use platform default with large headings and readable body

## Planned next
- Add semantic tokens for trails/weather/safety states
- Add motion and interaction presets
- Add component primitives compatible with web/mobile
