# GoHealTrail Feature Matrix

## Must-have MVP
| ID | Feature | Owner | Priority | Notes |
|---|---|---|---|---|
| MVP-01 | Trail search and discovery | web, api | P0 | By state, difficulty, duration, family mode |
| MVP-02 | Trail detail view | web, mobile | P0 | Safety notes, status, photos, route summary |
| MVP-03 | Trip planner | web, mobile | P0 | Multi-day itinerary + checklist |
| MVP-04 | Offline trail package | mobile | P0 | Selected route + essential metadata cached |
| MVP-05 | Weather + alerts | web, mobile, api | P0 | Monsoon/closure warnings + severity |
| MVP-06 | SOS + emergency share | mobile, api | P1 | Share live location + one-tap contacts |
| MVP-07 | Community trail updates | web, mobile | P1 | Condition, closure, leech/slippery reports |
